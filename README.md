# Dhanashri Bajbalkar - Portfolio | CodeAlfa Task 3

A responsive personal portfolio website built with **HTML, CSS and JavaScript**.

## Features
- Responsive layout for desktop, tablet and mobile
- About, Skills, Projects, Resume and Contact sections
- Smooth scrolling navigation
- Scroll reveal animations
- Hover effects
- Mobile navigation menu
- Interactive contact form demo
- GitHub/LinkedIn links
- Clean modern UI
- No external libraries required

## How to Run
1. Extract the ZIP file.
2. Open the `Dhanashri_Portfolio_Task3` folder.
3. Double-click `index.html`.
4. The portfolio will open in your browser.

For best development experience, open the folder in VS Code and use Live Server.

## GitHub Pages Deployment
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and other files.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save.
7. GitHub will provide your live portfolio URL.
